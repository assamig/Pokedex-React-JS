## ✨ Quick Reference (Consulta Rápida)

### useState em 1 segundo
```javascript
const [estado, setEstado] = useState(valorInicial)
```
- Guarda informações
- Muda com `setEstado(novo)`

### useEffect em 1 segundo
```javascript
useEffect(() => {
  // Código aqui roda quando dependências mudam
}, [dependências])
```
- Faz coisas automaticamente
- Roda quando dependências mudam

### Props em 1 segundo
```javascript
<Componente dados={algo} />  // Pai manda
function Componente({ dados }) { }  // Filho recebe
```
- Passa dados de pai para filho

### Condicional em 1 segundo
```javascript
{condição && <ComponenteAqui />}  // Mostra se verdadeiro
```
- Renderização condicional
